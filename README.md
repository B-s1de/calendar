# Расписание психологии личности

Автоматически формирует расписание для группы **26.М05-пс**
из расписания СПбГУ и публикует его через GitHub Pages.

Workflow обновляет файл каждые 6 часов.

## iPhone

На iPhone откройте:
**Настройки → Календарь → Учетные записи → Добавить учетную запись → Другое → Добавить подписной календарь**

Вставьте URL `https://B-s1de.github.io/ИМЯ-РЕПОЗИТОРИЯ/spbu.ics`.
