# СПбГУ → iPhone Calendar

Автоматически формирует iCalendar (`spbu.ics`) для группы **26.М05-пс**
из расписания СПбГУ (`studentGroupId=459496`) и публикует его через GitHub Pages.

## Установка

1. Создайте публичный GitHub repository.
2. Загрузите содержимое этого проекта в `main`.
3. Откройте **Settings → Pages** и в **Build and deployment → Source** выберите **GitHub Actions**.
4. Запустите workflow **Update SPbU calendar** вручную один раз во вкладке **Actions**.
5. После успешного запуска календарь будет доступен по:
   `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/spbu.ics`

Workflow обновляет файл каждые 6 часов.

## iPhone

На iPhone откройте:
**Настройки → Календарь → Учетные записи → Добавить учетную запись → Другое → Добавить подписной календарь**

Вставьте URL `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/spbu.ics`.

После этого iPhone будет периодически обновлять подписку.
